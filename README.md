# FumeSociety

A static shop. Upload this folder to GitHub Pages, Netlify, or any host that serves files.

Nothing to install. No Node. No Python. The catalog is already `catalog/products.json`, and the photographs are already in `catalog/images/`.

Open `index.html` through the host (a file opened from the desktop cannot load the catalog). Pages use hash links (`#/collection`, `#/product/...`), so the host does not need rewrites.

`CNAME` keeps https://fumesociety.com. Leave `.nojekyll` in place.

English is the default. Arabic is the button in the header. Orders open WhatsApp on +964 750 893 7745.
